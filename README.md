# ДЭ 2027 · Разработчик веб и мультимедийных приложений

Учебный маршрут на основе [2026-demo-template](https://github.com/OlgaKraven/2026-demo-template), с университетским оформлением, гидами, тренировкой и пробным экзаменом.

**КИМ 09.02.07-3-2027, ГИА базового уровня: 3 задания, 210 минут, 75 баллов.** Источники предоставлены пользователем; в materials находятся неизменённый КИМ, рекомендации и архив приложений именно БУ. На сайте есть полное условие базового образца, ссылки на страницы и хеши файлов. ПА и профильная вариативная часть не используются.

## Просмотр результата

- [Опубликованный учебный курс](https://olgakraven.github.io/demo-rvpm-2027/) — общедоступная версия после успешной публикации GitHub Pages.
- [Локальный курс](http://127.0.0.1:4197/) — после `npm run preview`.
- [PHP + MySQL в XAMPP](http://localhost/conference-rvpm-2027/) — после установки примера и запуска Apache/MySQL.
- [Flask](http://127.0.0.1:5017/) — после запуска `python -m flask --app app run --port 5017` из папки примера с выбранной базой.

Адреса localhost и 127.0.0.1 относятся к компьютеру читателя. Кнопки открытия примеров также находятся на сайте в разделе «Примеры».

## Учебный сайт

Документы → проектирование ER → создание БД и выгрузка → формы и сервер → дизайн → интерактивность → проверка и Git. Эти семь учебных этапов раскрывают три официальных задания, а не заменяют их. На карте маршрута выбирают стек и этап. В карточке этапа условия и файлы расположены отдельно от шагов, а результат проверяется на экране «Что сохранить». На последнем шаге проектирования интерактивная ER-диаграмма показывает цепочку «фраза КИМ → сущность → поля», происхождение каждого поля и связи FK → PK. Отдельный этап БД содержит реальные скриншоты phpMyAdmin, создание таблиц, FK, начальные данные, экспорт SQL и PDF. Материалы задания — текст, 25 изображений и стиль — просматриваются внутри сайта без скачивания.

В тренировке используется официальный образец «Конференции.РФ». Доступны общий таймер и таймер задания, пауза, отметки самопроверки и завершения задания. Пробный экзамен содержит 30 авторских вариантов по структуре базового КИМ. У каждого свои условие, каталог, палитра и прогресс. Отсчёт в пробном экзамене идёт без паузы. Условия и CSV скачиваются по одному или общим архивом. Браузер сохраняет таймеры и отметки самопроверки локально.

## Проверяемые примеры

- [Flask](examples/conference-portal-flask/): Python, Jinja, SQLite или MySQL/MariaDB. Основа — [conference-portal-flask](https://github.com/OlgaKraven/conference-portal-flask), версия 1c8001c. Добавлен рабочий адаптер MySQL, схема и инструкция Windows/XAMPP.
- [PHP + MySQL](examples/conference-portal-php/): PHP 8.2, PDO, XAMPP. Отдельный воспроизводимый проект с аналогичным пользовательским сценарием. Python для его запуска не нужен.

В разделе «Обучение» для Flask есть девять шагов сборки, для PHP — шесть. На первом шаге каждого стека доступен ZIP с учебным каркасом. В карточках указаны фрагменты, места вставки и проверки результата. Адрес карточки можно скопировать из адресной строки вместе с выбранным стеком и номером шага. В разделе «Преподавателю» стек презентации выбирается отдельно от учебного маршрута.

Оформление, графика и управление показом перенесены из [эталона ДКИП](https://github.com/OlgaKraven/2027-dkip-demo/tree/6c24f149fc8a449b6dc42eb12053df46259ed989). Кнопка «Содержание» и ссылки на слайде с оглавлением открывают разделы напрямую. Кнопка «Режим показа» создаёт окно аудитории в том же браузере, а у преподавателя открывается сценарий занятия. В разделе «Преподавателю» можно скачать PDF выбранного стека с кликабельным оглавлением. Общедоступный PDF формируется без локальных данных преподавателя. Для личного титула используйте «Печать / сохранить PDF» в самой презентации.

Оба проекта включаются в ZIP при сборке. Базы, сессии, .venv и секреты в архив не входят. Учебные реквизиты администратора Conf2027 / Demo77 взяты из КИМ. Примеры используют разные базы и несовместимые форматы хешей паролей.

Курс сохраняет красное университетское оформление. Сами примеры используют синюю палитру и PT Sans из руководства КИМ. Демонстрационные названия помещений не выдаются за официальные исходные данные.

## Сборка

Node.js 22+:

```sh
npm run build
npm test
npm run preview
```

Откройте http://127.0.0.1:4197. GitHub Pages публикует статический курс и ZIP; серверные примеры запускаются отдельно на компьютере. GitHub Actions проверяет курс, Flask/SQLite и синтаксис PHP перед публикацией.

Для локальной генерации PDF выполните `npm ci`, `npx playwright install chromium` и после сборки `npm run export:pdf`. GitHub Actions выгружает обе презентации вместе с сайтом.

Проверка PHP по HTTP: `python tests/php-smoke.py`; по умолчанию используется http://127.0.0.1/conference-rvpm-2027/index.php. Тест создаёт только синтетические данные в запущенном учебном примере.

Правила для новых проектов находятся в [AGENTS.md](AGENTS.md). Сохраняйте этот файл при создании проекта из шаблона; Codex автоматически читает его в репозитории.
