# ДЭ 2027 · Разработчик веб и мультимедийных приложений

Подготовка к ГИА базового уровня по КИМ 09.02.07-3-2027. В экзамене три задания на 210 минут, максимальная оценка — 75 баллов.

В образце задания нужно спроектировать базу данных, разработать портал «Конференции.РФ» и проверить его работу. В курсе доступны условия базового образца, критерии оценки, обучение, тренировка и пробный экзамен.
