# Проверка готовности по требованиям чата

Дата: 21 сентября 2026 года.

## Выполнено

- Сохранены университетское оформление, светлая/тёмная темы, меню справочных разделов справа на широком экране и обучение Git.
- Курс использует КИМ 09.02.07-3-2027, ГИА БУ: 3 задания, 210 минут, 75 баллов.
- Семь этапов: документы → ER → создание БД и выгрузка → сервер и формы → дизайн → интерактивность → проверка и Git. Гид расположен до описания этапа.
- Для элементов ER показаны исходные требования и происхождение полей; технические дополнения отмечены отдельно.
- Создание таблиц, ключей, импорт данных, Designer, PDF и SQL разобраны по шагам с 11 реальными снимками phpMyAdmin.
- Flask собирается из стартового архива по 9 шагам: файл, место вставки, код, проверка результата. Для PHP указаны файлы и области изменений.
- Оба примера доступны для скачивания; инструкции запуска предшествуют ссылкам на локальные приложения. Код имеет контрастный фон.
- Тренировка содержит официальный образец и таймер с паузой. Создание своей тренировки скрыто. Пробный экзамен содержит 30 авторских аналогов с отдельными данными и прогрессом, без паузы.
- Справочник ведёт к учебным действиям. Условие, 25 изображений и руководство по стилю доступны для просмотра; дублирующие ссылки и кнопка открытия опубликованного курса убраны.
- Презентация автоматически включает введение, учебные этапы, ER, все снимки БД и приложений, руководство по стилю и иллюстрации БУ. Есть краткий показ.
- ФИО, должность и кафедра / лаборатория преподавателя сохраняются локально и включаются во вводный слайд.
- Правила развития новых проектов находятся в AGENTS.md.

## Проверки

- Сборка курса и 8 автоматических проверок проходят.
- Flask: 8 тестов с SQLite и 8 с MariaDB; восстановление приложения из учебных блоков проходит те же 8 тестов.
- PHP: проверка синтаксиса и HTTP-сценарии регистрации, входа, прав, CSRF, бронирования и отзывов проходят на XAMPP.
- Начальные SQL-данные обоих стеков проверены в отдельных временных базах.
- В браузере проверены мобильная ширина 390px, читаемость кода в двух темах, материалы, таймер, переключение вариантов, презентация и сохранение новых полей преподавателя.

## Границы результата

GitHub Pages размещает учебный курс. Серверные примеры PHP и Flask запускаются локально по встроенным инструкциям. Проверка не является гарантией отсутствия всех ошибок. Авторские 30 вариантов не являются официальными вариантами КИМ; автоматическая оценка и отправка решения не реализованы. Правила AGENTS.md применяются в репозитории, а при создании отдельного проекта должны переноситься вместе с шаблоном.
