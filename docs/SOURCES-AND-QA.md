# Источники и проверка

## Источники

- Основа оформления и учебных правил: OlgaKraven/2026-demo-template, версия 11a9df6.
- Flask-пример: OlgaKraven/conference-portal-flask, версия 1c8001c. В этой копии добавлена поддержка MySQL/MariaDB; исходный репозиторий не изменён.
- КИМ 09.02.07-3-2027 Том 1 предоставлен пользователем. Используется только ГИА ДЭ БУ: длительность — страница 7; баллы — таблица 7, страница 13; задания и время — таблица на странице 29; полный образец — страницы 33–37. Соседний образец ПА не используется.
- Из предоставленного архива приложений выбран вложенный архив БУ. Он сохранён как materials/basic-inputs.zip; руководство по стилю — materials/style-guide.pdf. PDF КИМ и рекомендации сохранены без правок.
- SHA-256 исходных PDF и архива формируется сборкой в downloads/source-manifest.json.
- Каталог из шести помещений — демонстрационные данные Flask-примера. PHP использует тот же каталог в rooms.json. Технические поля и дополнительные ограничения отмечены в интерактивном разборе ER.

## Проверки 21 сентября 2026

- Flask: 8 тестов SQLite и 8 тестов MariaDB 10.4.32. Базы для MySQL-тестов создаются отдельно и удаляются после проверки.
- PHP 8.2.12: синтаксис трёх PHP-файлов; HTTP-сценарий регистрации, входа, заявки, админских статусов и отзыва, включая ошибки, CSRF и права владельца. Развёрнут через Apache/XAMPP в отдельной папке и базе.
- Статический курс: 8 тестов, проверяющих базовый комплект, оба маршрута, происхождение всех полей ER, таймер, 30 вариантов, сборку каркаса и наличие материалов.
- Учебный каркас Flask запускается с заглушками; автоматическая подстановка всех фрагментов из уроков восстанавливает приложение, которое проходит 8 интеграционных тестов.
- База conference_er_lesson создана отдельно в phpMyAdmin: users настроена через форму, остальные таблицы импортированы из SQL. Скриншоты и реальные SQL/PDF-выгрузки сохранены в materials/database.
- В браузере проверены 30 вариантов и изоляция заметок, просмотр условия/25 изображений/руководства внутри сайта, переходы справочника к шагам, контраст кода в обеих темах и обновлённая презентация со скриншотами.
- Браузер: переключение PHP/Flask, исходники, презентация, ER, пауза после перезагрузки, отсутствие паузы экзамена, страницы примеров. Проверена ширина 390 px; снимки работающих примеров находятся в materials/screenshots.

GitHub Actions повторяет SQLite-тесты, синтаксис PHP и тесты курса перед публикацией. Локальная HTTP-проверка PHP создаёт синтетические записи; они не попадают в скачиваемые архивы. Приложения не выполняют реальную оплату, рассылку и резервирование временных интервалов.
