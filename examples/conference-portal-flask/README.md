# Конференции.РФ — Flask

Учебный портал бронирования помещений для всероссийских конференций. Реализован по заданию базового уровня на Flask, Jinja и SQLite или MySQL/MariaDB; интернет и внешние CDN для работы не нужны.

## Запуск на Windows и XAMPP

Начните с [пошаговой инструкции WINDOWS.md](docs/WINDOWS.md): она описывает оба режима базы, создание отдельной базы MySQL и проверку приложения. MySQL использует `schema-mysql.sql`, SQLite — `schema.sql`.

## Возможности

- регистрация с серверной валидацией логина, пароля, ФИО, телефона и e-mail;
- безопасные хеши паролей Werkzeug и авторизация через подписанную сессию;
- CSRF-защита, ограничение частоты входа/регистрации и защитные HTTP-заголовки;
- каталог аудиторий, коворкингов и кинозалов с фильтрами;
- создание заявки с выбором площадки, даты, времени и способа оплаты;
- личный кабинет со статусами заявок;
- отзыв только после статуса «Завершено», один отзыв на заявку;
- административная панель с поиском, фильтрами, карточками и сменой статусов;
- адаптивный интерфейс, в том числе для экрана 390 × 844 px;
- локальные изображения и PT Sans из комплекта задания.

## Запуск

Нужен Python 3.9 или новее.

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements.txt
    python app.py

Откройте http://127.0.0.1:5000. База создаётся и наполняется каталогом автоматически при первом запуске.

## Пошаговый урок для MySQL

Если база MySQL уже создана, но таблиц и schema.sql ещё нет, используйте отдельный
[пошаговый урок](docs/flask-mysql-step-by-step.md). Он показывает подключение,
описание схемы моделями SQLAlchemy, первую миграцию, маршруты, авторизацию и тесты.

Чтобы осознанно пересоздать базу и удалить текущие данные:

    flask --app app init-db --yes

Для рабочего развёртывания задайте случайный SECRET_KEY и включите HTTPS-cookie через COOKIE_SECURE=1. Без переменной приложение создаёт постоянный случайный ключ в instance/secret_key с правами 0600.

## Структура

- app.py — фабрика приложения, маршруты, валидация и работа с БД;
- schema.sql — SQL-схема и ограничения целостности;
- templates — Jinja-шаблоны;
- static — локальные стили, JS, изображения и шрифты;
- docs/er-diagram.md — ER-диаграмма и описание связей;
- tests — интеграционные тесты Flask test client.

SQLite-файл и секрет создаются в instance и исключены из Git.
