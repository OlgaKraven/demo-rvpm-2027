# Конференции.РФ · Flask + MySQL / MariaDB

Готовый учебный пример по КИМ 09.02.07-3-2027, ГИА базового уровня. Этот README описывает запуск на Windows с MySQL/MariaDB из XAMPP и локальными библиотеками. Для самостоятельного написания проекта следуйте разделу «Обучение» курса.

## 1. Подготовьте программы и распакуйте ZIP

До работы без интернета установите **Python 3.12 для Windows x64** и **XAMPP 8.2.12** в `C:\xampp`. При установке Python оставьте Python Launcher. Ссылки и снимки установки находятся в локальном `preparation.html` рядом с README. VS Code нужен для редактирования; запуск ниже выполняется из PowerShell.

Распакуйте весь ZIP, например в `C:\Exam\conference-flask`. В папке должны быть `app.py`, `mysql_backend.py`, `requirements.txt`, `database-filled.sql` и папки `templates`, `static`, **`wheels`**. Запуск из окна ZIP не подходит. Папку `.venv` создайте заново на этом компьютере.

Запустите XAMPP Control Panel и нажмите **Start** у **Apache** и **MySQL**. Apache нужен для phpMyAdmin; сам портал обслуживает Flask. Посмотрите порт MySQL в панели: в стандартной установке это `3306`.

## 2. Импортируйте заполненную базу

1. Откройте `http://localhost/phpmyadmin`.
2. Слева нажмите **Создать БД** / **Новая**. Введите `conference_rvpm_2027`, выберите сравнение `utf8mb4_unicode_ci` и нажмите **Создать**. Нужна отдельная новая пустая база. Если имя занято, выберите другое и затем укажите его в `MYSQL_DATABASE`.
3. Выберите созданную базу слева → **Импорт** → **Выберите файл**. Укажите `database-filled.sql` именно из этого ZIP. Формат — **SQL**, кодировка файла — **utf-8**. Прокрутите вниз и нажмите **Импорт** / **Вперёд**.
4. После сообщения об успешном импорте во вкладке **Структура** должны появиться пять таблиц: `users`, `rooms`, `applications`, `reviews`, `rate_limits`.
5. Откройте `rooms` → **Обзор**: должно быть **6 помещений**, включая «Балтика» с вместимостью **120**. В `users` должна быть одна запись `Conf2027`, `is_admin = 1`. Заявки, отзывы и ограничитель попыток пока пусты; они наполняются при работе программы.

`database-filled.sql` содержит структуру, связи, ограничения значений, каталог и администратора. Базы PHP и Flask должны быть разными: форматы хешей паролей у них различаются.

`schema-mysql.sql` содержит только структуру, а `schema.sql` предназначен для внутренних SQLite-тестов. Для этого запуска используйте импортированную базу MySQL. После импорта команда `init-db` не нужна: она пересоздаёт таблицы и удаляет данные.

## 3. Установите библиотеки без интернета

Откройте распакованную папку в Проводнике. Щёлкните правой кнопкой по свободному месту → **Открыть в Терминале** и выберите профиль **Windows PowerShell**. Измените первую строку, если выбрали другую папку:

```powershell
Set-Location 'C:\Exam\conference-flask'
py -3.12 --version
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --disable-pip-version-check --no-cache-dir --find-links .\wheels -r requirements.txt
```

Первая проверка должна показать Python **3.12.x**. Установка берёт Flask, PyMySQL, pytest и их зависимости только из `wheels`; `--no-index` отключает поиск пакетов в интернете. Активация окружения и изменение политики PowerShell не требуются: команды прямо указывают Python из `.venv`.

Проверьте установленные пакеты:

```powershell
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -c "import flask, pymysql, pytest; print('Libraries OK')"
```

## 4. Запустите программу

В том же PowerShell задайте подключение и запустите сервер:

```powershell
$env:DB_BACKEND='mysql'
$env:MYSQL_HOST='127.0.0.1'
$env:MYSQL_PORT='3306'
$env:MYSQL_DATABASE='conference_rvpm_2027'
$env:MYSQL_USER='root'
$env:MYSQL_PASSWORD=''
.\.venv\Scripts\python.exe -m flask --app app run --host 127.0.0.1 --port 5017
```

Подставьте порт, имя базы и реквизиты своего MySQL. `root` с пустым паролем — стандартный локальный XAMPP. Пароль MySQL и пароль портала — разные реквизиты. Переменные действуют в текущем PowerShell; при новом запуске задайте их снова. `DB_BACKEND='mysql'` выбирает импортированную базу.

Оставьте сервер работающим и откройте `http://127.0.0.1:5017` в браузере. Для остановки нажмите **Ctrl+C** в окне сервера. Запуск `app.py` двойным щелчком и открытие HTML-шаблонов отдельно не заменяют запуск Flask.

1. В обычном окне браузера нажмите **Регистрация**. Введите логин `student27`, пароль и повтор пароля `ConfStudy27!`, ФИО `Ирина Соколова`, телефон `8(900)123-45-67`, e-mail `student27@example.test`. Это учебные данные. Нажмите **Создать пользователя**, затем войдите под новой записью. Если пользователь уже существует, используйте его пароль или другой логин и e-mail.
2. Откройте **Новая заявка**. Введите название `Учебная конференция`, выберите «Балтика», завтрашнюю дату, время `10:00`, **12** участников, оплату **При очном посещении**. Нажмите **Отправить заявку**. В **Моих заявках** должна появиться одна запись со статусом **Новая**. Отзыв до завершения недоступен.

После установки программ и локальных библиотек этот запуск работает без интернета: база, изображения, JavaScript, стили и шрифты находятся на компьютере.

## Если запуск не получился

- `Requested Python version ... not installed`: установите Python 3.12 x64 заранее. `py -0p` показывает установленные версии.
- `No matching distribution found`: проверьте, что распаковали весь ZIP, `wheels` не пуста и выбран Python 3.12 x64. Не убирайте `--no-index` ради экзаменационного запуска.
- `ModuleNotFoundError`: выполняйте команды через `.\.venv\Scripts\python.exe` из папки с `app.py`; повторите локальную установку из раздела 3.
- `Connection refused` / ошибка 2003: запустите MySQL в XAMPP и сверьте `MYSQL_PORT`. `Access denied` / ошибка 1045: сверьте `MYSQL_USER` и `MYSQL_PASSWORD`.
- `Unknown database` / отсутствует таблица: сверьте `MYSQL_DATABASE` и импорт в phpMyAdmin. Не импортируйте файл поверх заполненных таблиц и не применяйте `init-db` для исправления подключения.
- Порт `5017` занят: остановите свой прежний сервер через **Ctrl+C** или укажите `--port 5018` и откройте `http://127.0.0.1:5018`.
- После ошибки регистрации введите оба пароля заново. Логин — не менее 6 латинских букв/цифр, пароль — не менее 8 символов; телефон — точно по образцу.

## Локальные пакеты для собственного проекта

Готовые `requirements.txt` и `wheels` из ZIP можно заранее перенести на учебный компьютер. Для нового проекта создайте свою `.venv` и установите пакеты командой из раздела 3. Если нужен новый комплект, на компьютере с интернетом и **Python 3.12 x64** заранее выполните:

```powershell
py -3.12 -m pip download --only-binary=:all: -r requirements.txt -d wheels
```

Перенесите весь комплект и проверьте установку в новой `.venv` через `--no-index` до экзамена. Для редактирования в VS Code при наличии расширения Python выберите `.venv\Scripts\python.exe` командой **Python: Select Interpreter**. Терминальный запуск выше работает и без расширения.

## Файлы и проверки разработки

`app.py` — маршруты и обработчики; `mysql_backend.py` — подключение MySQL; `templates` — формы; `static` — локальные ресурсы. `rooms.json` содержит шесть демонстрационных помещений. Тестовый пользователь и каталог не являются официальными данными КИМ. Поля форм, статусы и роль администратора основаны на задании. `rate_limits` — технический ограничитель частоты входа и регистрации.

Необязательная проверка `.\.venv\Scripts\python.exe -m pytest -q tests/test_app.py` использует временную SQLite-базу и не заменяет проверку MySQL и двух ролей по шагам выше. Рабочую базу она не меняет.

Пример не выполняет настоящую оплату и не проверяет пересечение времени бронирования. Для сдачи сохраняйте собственный код, SQL, ER-схему, README и историю Git по инструкции площадки; `.venv`, `instance`, `.env` и локальные пароли в репозиторий не включайте.
