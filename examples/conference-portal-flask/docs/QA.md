# Проверка примера · 21 сентября 2026

Исходная версия: OlgaKraven/conference-portal-flask, коммит 1c8001c.

- Исходный и дополненный проекты: по 8 интеграционных тестов прошли на SQLite.
- Добавлен режим DB_BACKEND=mysql: PyMySQL, отдельная схема InnoDB, преобразование параметризованных запросов и обработка ограничений.
- Все те же 8 тестов прошли на MariaDB 10.4.32 из XAMPP 8.2.12, в изолированных тестовых базах.
- Проверены регистрация, серверная валидация, хеши паролей, повторный логин, CSRF, ограничение попыток, запрет админки, заявка, статусы и отзыв после завершения.

Среда: Windows, Python 3.12, Flask 3.1.3, PyMySQL 1.2.3. SQLite сохранён для быстрого старта. См. WINDOWS.md для воспроизведения проверок.

Оценка соответствия КИМ не равна официальной оценке экзамена. Пример служит материалом для изучения и проверки своей реализации.
