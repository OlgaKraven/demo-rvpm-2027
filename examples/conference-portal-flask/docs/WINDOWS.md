# Запуск Flask на Windows

Полная последовательность находится в [README.md](../README.md): установка Python 3.12 x64 и XAMPP, импорт `database-filled.sql`, установка из `wheels` без интернета, переменные подключения MySQL, запуск Flask и проверка обеих ролей.

Выполняйте команды из распакованной папки с `app.py`. Не запускайте `init-db` после импорта: эта команда пересоздаёт таблицы. Иллюстрированная подготовка программ находится в `preparation.html` в корне архива.
