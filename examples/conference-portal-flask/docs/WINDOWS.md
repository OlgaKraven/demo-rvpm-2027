# Запуск в Windows: VS Code и XAMPP

Распакуйте архив, откройте папку `conference-portal-flask` в VS Code. Нужен Python 3.10+. Команды выполняются в терминале **из папки с app.py**.

## Подготовка

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Активация окружения не требуется. Установка зависимостей использует интернет. Для экзамена подготовьте подходящие колёса пакетов заранее: `pip download -r requirements.txt -d wheelhouse`, затем офлайн `pip install --no-index --find-links wheelhouse -r requirements.txt`.

## Быстрый запуск: SQLite

```powershell
$env:DB_BACKEND='sqlite'
.\.venv\Scripts\python.exe -m flask --app app run --port 5017
```

Откройте http://127.0.0.1:5017. Таблицы и каталог создаются автоматически в `instance/conference.sqlite3`. XAMPP для этого режима не нужен.

## MySQL / MariaDB из XAMPP

1. В XAMPP Control Panel запустите **MySQL**. Apache нужен для phpMyAdmin; Python-приложение обслуживает Flask.
2. Откройте http://localhost/phpmyadmin. Создайте **новую пустую** базу `conference_rvpm_2027` с кодировкой utf8mb4. Не выбирайте базу другого проекта.
3. В PowerShell задайте параметры и запустите приложение:

```powershell
$env:DB_BACKEND='mysql'
$env:MYSQL_HOST='127.0.0.1'
$env:MYSQL_PORT='3306'
$env:MYSQL_DATABASE='conference_rvpm_2027'
$env:MYSQL_USER='root'
$env:MYSQL_PASSWORD=''
.\.venv\Scripts\python.exe -m flask --app app run --port 5017
```

Пример root без пароля предназначен только для стандартного локального XAMPP. Если ваша учётная запись другая, подставьте её параметры. Приложение не создаёт саму базу. В пустой базе оно создаёт пять таблиц из `schema-mysql.sql`, шесть помещений и учебного администратора.

Не импортируйте `schema.sql` в MySQL: это SQLite-синтаксис. В непустой базе приложение не запускает создание схемы. `flask --app app init-db --yes` явно удаляет и создаёт таблицы заново — для обычного запуска эта команда не нужна.

## Сценарий проверки

Зарегистрируйте тестового пользователя с логином от 6 символов и паролем от 8. Создайте заявку на будущую дату. Войдите администратором **Conf2027 / Demo77**, смените статус на «Мероприятие назначено», затем «Завершено». Вернитесь пользователем и оставьте отзыв. Проверьте запрет чужой заявки и административного раздела.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Для того же набора тестов на локальной MariaDB:

```powershell
$env:PORTAL_TEST_MYSQL='1'
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты создают случайные базы с префиксом `rvpm_test_` и удаляют только их. Тестовой учётной записи нужны CREATE/DROP DATABASE. Рабочая база не используется. Уберите переменную `PORTAL_TEST_MYSQL`, чтобы вернуться к SQLite-тестам.

## Что сохранить для сдачи

Исходники, SQL/ER-схему, локальные ресурсы, requirements.txt и README. Не включайте `.venv`, `instance`, `.env`, секретный ключ и личные данные. Фиксируйте начало и завершение каждого задания в Git; отправляйте результат в индивидуальный репозиторий.

## Ограничения

Это учебный пример, а не промышленная система бронирования: нет реальной оплаты, писем и проверки пересечения интервалов занятости. Правила КИМ не задают такую проверку. Техническая защита входа использует простой ограничитель попыток. Для публичного размещения измените учебные реквизиты, настройте HTTPS, SECRET_KEY и сервер WSGI. Учебный сайт GitHub Pages сам Flask не запускает.
