# Проверка PHP-примера

21 сентября 2026, Windows, XAMPP 8.2.12, PHP 8.2.12, MariaDB 10.4.32.

Синтаксис PHP проверен через php -l. Проект развёрнут в отдельной папке htdocs, использует новую базу conference_php_2027.

HTTP-проверка tests/php-smoke.py прошла: открытие страниц, неверная регистрация, успешная регистрация, повторный логин/e-mail, неверный пароль, сессия, запрет админки, CSRF, создание заявки, запрет чужой заявки и раннего отзыва, смена двух статусов, отзыв после завершения и запрет повторного отзыва. Данные проверки синтетические.

Сценарий не является официальной оценкой экзамена. Остаются ограничения из README: нет оплаты, писем и проверки пересечения бронирований.
