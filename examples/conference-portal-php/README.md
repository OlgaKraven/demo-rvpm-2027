# Конференции.РФ · PHP + MySQL / XAMPP

Готовый учебный пример по КИМ 09.02.07-3-2027, ГИА базового уровня. Этот README позволяет восстановить базу и проверить программу на Windows. Для самостоятельного написания проекта следуйте разделу «Обучение» курса.

## 1. Подготовьте программы и распакуйте ZIP

До работы без интернета установите **XAMPP 8.2.12** в `C:\xampp`. В комплекте есть PHP 8.2, MariaDB, phpMyAdmin, расширения `pdo_mysql` и `mbstring`. Отдельные библиотеки Composer этому примеру не нужны. Ссылки на установщики и снимки установки находятся в локальном `preparation.html` рядом с этим README.

Распакуйте весь ZIP, например в `C:\Exam\conference-php`. В этой папке должны лежать `index.php`, `lib.php`, `database-filled.sql`, папка `static` с изображениями, стилями, JavaScript и шрифтами. Запуск из окна ZIP не подходит.

Запустите XAMPP Control Panel и нажмите **Start** у **Apache** и **MySQL**. Apache открывает phpMyAdmin, а сам пример ниже запускается встроенным сервером PHP. Посмотрите порт MySQL в панели: в стандартной установке это `3306`.

## 2. Импортируйте заполненную базу

1. Откройте `http://localhost/phpmyadmin`.
2. Слева нажмите **Создать БД** / **Новая**. Введите `conference_php_2027`, выберите сравнение `utf8mb4_unicode_ci` и нажмите **Создать**. Нужна отдельная новая пустая база. Если имя занято, выберите другое и затем укажите его в `MYSQL_DATABASE`.
3. Выберите созданную базу слева → **Импорт** → **Выберите файл**. Укажите `database-filled.sql` именно из этого ZIP. Формат — **SQL**, кодировка файла — **utf-8**. Прокрутите вниз и нажмите **Импорт** / **Вперёд**.
4. После сообщения об успешном импорте во вкладке **Структура** должны появиться пять таблиц: `users`, `rooms`, `applications`, `reviews`, `rate_limits`.
5. Откройте `rooms` → **Обзор**: должно быть **6 помещений**, включая «Балтика» с вместимостью **120**. В `users` должна быть одна запись `Conf2027`, `is_admin = 1`. Заявки, отзывы и ограничитель попыток пока пусты; они наполняются при работе программы.

`database-filled.sql` содержит структуру, связи, ограничения значений, каталог и администратора. Базы PHP и Flask должны быть разными: форматы хешей паролей у них различаются.

`schema.sql` содержит только структуру. После импорта заполненной базы запускать `setup.php` не требуется.

## 3. Запустите программу из PowerShell

Откройте распакованную папку в Проводнике. Щёлкните правой кнопкой по свободному месту → **Открыть в Терминале** и выберите профиль **Windows PowerShell**. Выполните команды ниже; если выбрали другую папку, измените первую строку.

```powershell
Set-Location 'C:\Exam\conference-php'
& C:\xampp\php\php.exe -m
```

В списке должны быть `pdo_mysql` и `mbstring`. Затем в том же окне выполните:

```powershell
$env:MYSQL_HOST='127.0.0.1'
$env:MYSQL_PORT='3306'
$env:MYSQL_DATABASE='conference_php_2027'
$env:MYSQL_USER='root'
$env:MYSQL_PASSWORD=''
& C:\xampp\php\php.exe -S 127.0.0.1:8087
```

Порт, имя базы, пользователь и пароль должны совпадать с вашим MySQL. `root` с пустым паролем — стандартный локальный XAMPP. Пароль MySQL и пароль входа на портал — разные реквизиты. Переменные действуют в текущем окне PowerShell; при новом запуске задайте их снова.

Оставьте окно сервера открытым. Перейдите в браузере на `http://127.0.0.1:8087`. PHP выполняется сервером: открытие `index.php` двойным щелчком не запускает программу. Для остановки сервера нажмите **Ctrl+C** в его окне.

## 4. Проверьте обе роли

1. В обычном окне браузера нажмите **Регистрация**. Введите логин `student27`, пароль и повтор пароля `ConfStudy27!`, ФИО `Ирина Соколова`, телефон `8(900)123-45-67`, e-mail `student27@example.test`. Это учебные данные. Нажмите **Зарегистрироваться**, затем войдите под новой записью. Если пользователь уже существует, используйте его пароль или другой логин и e-mail.
2. Откройте **Новая заявка**. Введите название `Учебная конференция`, выберите «Балтика», завтрашнюю дату, время `10:00`, **12** участников, оплату **При очном посещении**. Нажмите **Отправить заявку**. В **Моих заявках** должна появиться одна запись со статусом **Новая**. Отзыв до завершения недоступен.
3. Откройте отдельное окно **инкогнито** Chrome / **InPrivate** Edge через **Ctrl+Shift+N**, перейдите по тому же адресу и войдите как **Conf2027 / Demo77**. Две обычные вкладки используют одну сессию, поэтому для двух ролей нужны обычное и отдельное приватное окна.
4. В **Панели администратора** найдите заявку. В поле **Новый статус** выберите **Мероприятие назначено**, нажмите **Сохранить статус**. Обновите кабинет пользователя и сверьте статус. Затем администратором сохраните **Завершено**.
5. Обновите кабинет пользователя. Выберите оценку **5**, введите `Зал подходит для учебной конференции` и нажмите **Оставить отзыв**. Текст и оценка должны сохраниться; два обновления страницы не создают дубликатов заявки и отзыва.
6. Нажмите **Выйти**. Кабинет должен требовать входа, а обычному пользователю пункт **Администратор** недоступен. Сохранённые строки можно сверить через **Обзор** таблиц в phpMyAdmin.

После установки программ и локальных библиотек этот запуск работает без интернета: база, изображения, JavaScript, стили и шрифты находятся на компьютере.

## Если запуск не получился

- `could not find driver` / отсутствует `mbstring`: проверьте `php.exe -m`. В `C:\xampp\php\php.ini` включите строки `extension=pdo_mysql` и `extension=mbstring`, убрав начальный `;`, затем остановите и заново запустите сервер PHP.
- `Connection refused`: запустите MySQL в XAMPP и сверьте `MYSQL_PORT` с портом в панели.
- `Access denied`: исправьте `MYSQL_USER` / `MYSQL_PASSWORD` в том же PowerShell и перезапустите сервер.
- `Unknown database` / `Table ... doesn't exist`: сверьте `MYSQL_DATABASE` и результат импорта в выбранную базу. Не импортируйте файл повторно поверх заполненных таблиц.
- Порт `8087` занят: остановите свой прежний сервер через **Ctrl+C** или запустите на `8088` и откройте `http://127.0.0.1:8088`.
- После ошибки регистрации поля паролей очищаются: введите оба заново. Логин — не менее 6 латинских букв/цифр, пароль — не менее 8 символов; телефон вводится точно по образцу.

## Файлы и происхождение данных

`index.php` — формы и обработчики; `lib.php` — подключение PDO и общие функции; `static` — локальные ресурсы; `rooms.json` — демонстрационный каталог. Поля регистрации, заявки, статусы и роль администратора основаны на КИМ. Шесть помещений и тестовый пользователь — данные примера. `rate_limits` служит техническому ограничению частоты входа и регистрации.

Пример не выполняет настоящую оплату и не проверяет пересечение времени бронирования. Для сдачи сохраняйте собственный код, SQL, ER-схему, README и историю Git по инструкции площадки; локальные пароли и файлы сессий в репозиторий не включайте.
