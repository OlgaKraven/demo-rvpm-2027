0. Установка и настройка программ

Flask и MySQL без интернета

  1. Распакуйте ZIP Flask. В phpMyAdmin создайте новую пустую базу conference_rvpm_2027 с кодировкой utf8mb4. Откройте её → «Импорт» → выберите database-filled.sql → «Импорт». В таблице rooms должно быть шесть помещений, в users — администратор.
  2. Откройте PowerShell в распакованной папке и выполните команды. Подставьте порт и реквизиты своего MySQL. Пустой пароль показан для стандартного локального XAMPP.
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --disable-pip-version-check --no-cache-dir --find-links .\wheels -r requirements.txt
$env:DB_BACKEND='mysql'
$env:MYSQL_HOST='127.0.0.1'
$env:MYSQL_PORT='3306'
$env:MYSQL_DATABASE='conference_rvpm_2027'
$env:MYSQL_USER='root'
$env:MYSQL_PASSWORD=''
.\.venv\Scripts\python.exe -m flask --app app run --port 5017

Откройте http://127.0.0.1:5017. Войдите как Conf2027 / Demo77. Для проверки роли посетителя зарегистрируйте отдельного пользователя и подайте заявку. После импорта заполненной базы команду init-db не запускайте.

Пакеты для нового проекта

Заранее скопируйте requirements.txt и wheels из архива или на компьютере с интернетом выполните py -3.12 -m pip download --only-binary=:all: -r requirements.txt -d wheels. На рабочем месте создайте новую .venv и примените команду установки с --no-index из примера. В VS Code выберите .venv\Scripts\python.exe через Python: Select Interpreter, если установлено расширение Python. При ошибке No matching distribution проверьте версию Python, архитектуру и комплектность wheels.

PHP и MySQL без интернета

В XAMPP уже есть PHP 8.2 и расширение pdo_mysql. Загрузка пакетов Composer для примера не требуется. Выполните & C:\xampp\php\php.exe -m и найдите pdo_mysql. Если расширение выключено, в C:\xampp\php\php.ini уберите ; перед extension=pdo_mysql и перезапустите Apache, если работаете через него.

В phpMyAdmin создайте новую пустую базу conference_php_2027 с кодировкой utf8mb4 и импортируйте database-filled.sql из ZIP PHP. Сверьте шесть помещений и администратора. Для локального просмотра через командную строку выполните в папке с index.php:

$env:MYSQL_HOST='127.0.0.1'
$env:MYSQL_PORT='3306'
$env:MYSQL_DATABASE='conference_php_2027'
$env:MYSQL_USER='root'
$env:MYSQL_PASSWORD=''
& C:\xampp\php\php.exe -S 127.0.0.1:8087

Откройте http://127.0.0.1:8087 и войдите как Conf2027 / Demo77. Для Apache вместо встроенного сервера можно распаковать проект в C:\xampp\htdocs\conference-rvpm-2027 и открыть http://localhost/conference-rvpm-2027/. Если настройки подключения отличаются от стандартных, укажите их в окружении запуска Apache.

ЧаВО об экзамене

Как распределены задания?

Три задания базового уровня КИМ 09.02.07-3-2027 выполняются в одном веб-проекте. Сверьте критерии по базе и серверу, оформлению и интерактивности с документами на этапе 0.

Можно ли пользоваться интернетом и своими заготовками?

КИМ, с. 23, предусматривает локальную сеть без доступа в интернет. Нужные зависимости и установщики подготовьте дома заранее. На экзамене используйте программы, локальную справку, файлы и носители, разрешённые организаторами. Git работает локально.

Можно ли выбрать PHP или Flask?

Курс показывает обе реализации. На экзамене выбирайте среду и технологии из тех, которые доступны и допускаются на площадке. Уточните это, доступ к СУБД и способ сдачи до начала работы.

Что делать, если не включается СУБД или не открываются файлы?

Сообщите эксперту номер места, ошибку и шаг, на котором она возникла. Для домашнего стенда проверьте журнал XAMPP, состояние службы и порт.

Что проверить перед сдачей?

Откройте сайт локально, проверьте регистрацию, заявку, смену статуса, допустимость отзыва и мобильный экран. Сохраните SQL, файлы проекта и остальные материалы в папке сдачи по инструктажу.
